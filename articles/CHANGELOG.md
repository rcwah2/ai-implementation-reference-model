# Article Change Log

This log records every published change to the articles in the AI Implementation Reference Model series, on GitHub and on [Substack](https://rwahai.substack.com/). Entries are listed newest first.

For how versions are numbered and archived, see [Versioning and Archive Policy](archive/README.md).

## How to Read an Entry

| Field | Meaning |
|---|---|
| Version | New version number of the article after the change |
| Type | **Initial release** · **Regulatory update** · **Correction** · **Clarification** · **Substantive revision** · **Editorial** |
| Change | What changed, in one or two sentences |
| Reason and source | Why it changed; for regulatory updates, the official or authoritative source |
| Regulatory register ID | The matching entry in the regulatory register, if applicable (for example, REG-001) |
| Approved | Date the author approved the change |
| GitHub | Commit or pull request for the change |
| Substack | Date the Substack post was updated and whether an update note or comment was added |
| Archived prior version | Link to the archived copy of the previous version |
